# Demo 演示脚本 · 截图清单 · PPT 大纲

面向赛题 1 的 5 分钟现场/录屏演示，以及配套的截图与答辩材料。所有页面路径均以部署后的根地址为基准（本地默认 `http://127.0.0.1/`）。

---

## 一、演示前准备

### 1.1 环境检查（提前 30 分钟）

```bash
cd deploy && bash healthcheck.sh http://<host>
```

确认：`status=ok`、`ai_key_configured=true`、`kb_ready=true`、6 个页面 200。若 `kb_ready=false`，先在宿主机执行 `git lfs pull` 并重建镜像，不要带着降级状态录屏。

### 1.2 演示数据准备

1. 注册一个演示账号（如 `demo_student`），完成 2~3 次问答，让掌握度与错题有数据；
2. 在学习空间上传 1 份笔记（如《导数公式整理》），供知识库检索命中；
3. 确认题库中有可抽题的知识点；
4. 提前打开 4 个标签页：首页、智能问答、仪表盘、知识图谱，避免现场输入网址。

### 1.3 关键提醒

- 演示用 **文本提问** 更稳，拍照识题作为加分项（`OCR_PROVIDER=qwen_vl` 时）；
- 网络不稳时把 `USE_REAL_AI=false` 的离线兜底作为 Plan B，但需口头说明是降级演示；
- 录屏分辨率 1920×1080，浏览器缩放 100%，隐藏书签栏。

## 五、答辩问答准备

**Q1：和直接问大模型有什么区别？**
A：三点——回答前先查学生本人的掌握度并据此选择策略；回答时用知识库与图谱提供可追溯证据；回答后把诊断、错题、计划写回档案。通用模型三次都做不到。

**Q2：数据合规怎么做？**
A：公共库是结构化生成的教研内容，不复制教材原文；用户资料按 `user_id` 隔离存储，私有向量库与公共库分通道；提示词注入有独立防护模块；演示环境使用虚构学生数据。

**Q3：图谱真的有用吗，还是可视化装饰？**
A：图谱参与检索排序，并返回 `graph_context` 与 `graph_contribution_rate`。当前评测中图谱上下文命中率 60%，连通率 100%，我们把它作为可度量的通道而非装饰——不达标就不会写进结论。

**Q4：为什么必须用华为云？**
A：MaaS 提供 OpenAI 兼容接口，代码只需改环境变量；RDS/DCS 承担多实例下的状态与异步任务；CodeArts 覆盖需求拆解到部署的全过程；ECS + 单镜像让私有化复制成本最低。

**Q5：成本与规模化？**
A：最小配置 1 台 4C8G ECS + MaaS 按量计费即可演示；机构私有化只换数据库地址，镜像与知识库可直接复用。B2B 按席位、B2C 按订阅，边际成本主要是推理 token。

**Q6：目前最大的不足？**
A：云端真实并发与时延数据尚未采集（服务器审批中），我们已列出复测计划与目标值；另外图谱边构建依赖相似度阈值，跨学科概念对齐还需要人工校验环节。

## 六、录屏与后期

- 工具：OBS（1920×1080，30fps，硬件编码）或系统自带录屏；
- 节奏：每个操作后停顿 1 秒，方便剪辑；鼠标移动放慢；
- 字幕：关键结论做硬字幕（工具路由、hit@5 100%、33.5ms、三级降级）；
- 片头 3 秒：作品名 + 一句话定位；片尾 3 秒：仓库地址 + 许可证；
- 输出：MP4（H.264），文件命名 `FZG-demo-v1.mp4`，同时保留一份 30 秒竖版用于传播。
